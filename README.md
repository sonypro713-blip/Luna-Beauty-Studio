Project Overview

Luna Beauty Studio is a self-initiated website project created to demonstrate how a beauty salon can present its services, showcase its work, and help customers contact the business.

The website features an elegant plum and blush color palette, clean layouts, and a responsive design for mobile and desktop devices.

Website Pages

- Home — Introduction, featured services, and salon highlights
- About — Salon story, values, and team
- Services — Beauty treatments and service listings
- Gallery — Beauty and salon image gallery
- Contact — Contact information and appointment inquiry

Features

- Responsive mobile-friendly layout
- Shared navigation and footer
- Service listings and pricing layout
- Beauty treatment gallery
- WhatsApp booking links
- Contact form that prepares booking details in WhatsApp
- Consistent visual design across pages

Technologies Used
